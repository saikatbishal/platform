# UI kit — Platform (the app)

One product, one surface: a mobile-first browser app, installable to the home
screen, entirely behind a Google sign-in. There is no marketing site and no
docs site in the source repository, so there is no second kit.

## What this recreates

`src/App.tsx` and the features it composes, at desktop width:

| Piece | Source |
| --- | --- |
| Full-bleed map, sign-in board hung top-right, corner nameplate, totals strip bottom-left | `src/App.tsx` |
| Station name board + bracket + lit canopy | `src/components/StationBoard.tsx`, `src/components/PlatformCanopy.tsx` |
| Log a journey | `src/features/journeys/AddJourneyForm.tsx` |
| Milestones | `src/features/stats/Milestones.tsx`, `milestones.ts` |
| Passport card | `src/features/passport/PassportCard.tsx` |
| Sign in / account menu | `src/features/auth/SignInButton.tsx`, `UserMenu.tsx` |

## What it deliberately does not recreate

The real map is hand-drawn SVG over a **Survey-of-India district file** — India
outline, 36 states, 760 districts, 454 rail lines, 214 cities and 8,696 station
dots on canvas, with pan/zoom in a ref, label collision, a level-of-detail
table, and journeys expanded through a routing graph so a line never crosses
the Bay of Bengal. All of that geometry is generated by `npm run assets` and
gitignored, so none of it is in the repository.

This kit draws the same three layers — sea, land, routes over a station field —
from public-domain Natural Earth geometry with d3-geo, twenty real stations
instead of 8,696, and straight legs instead of routed ones. It is the right
**look**; it is not the right **data**. Two consequences worth knowing:

- Natural Earth stops India at 35.50°N; the official boundary is 37.08°N.
  The real app never uses Natural Earth for this reason.
- Legs here are two-point lines, which the project's rules forbid in the app
  itself. They are drawn that way only because the routing graph is absent.

Also absent: the animated sea (wave glyphs and drifting specks with the ≈ pause
button), the visited-state land fill, and the canvas-rendered share image —
`PassportCardView` here is a DOM stand-in for a canvas the real app draws at
1200×630.

## Running it

Open `index.html`. It needs the network for d3, React and the Natural Earth
topology, and it needs `_ds_bundle.js` at the project root.
